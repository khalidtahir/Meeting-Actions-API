# Sample Transcripts

This folder contains **meeting minutes** (chat-style transcripts) for five projects. Each project has **one team** that meets over time. Use these as sample data to test the app: create a project, then import the transcripts **one meeting at a time** to initialize and update action items.

## Structure

- **ProjectAlpha** – API redesign (Sarah, David, Elena, James, Priya)
- **ProjectBeta** – Mobile app onboarding redesign (Nina, Omar, Lisa, Ken, Jade)
- **ProjectGamma** – Platform API (Max, Zoe, Leo, Mia, Eli)
- **ProjectDelta** – Search and discovery (Alex, Jordan, Sam, Taylor, Morgan)
- **ProjectEpsilon** – Internal analytics dashboard (Max, Zoe, Leo, Mia, Eli)

Each project folder contains:

- **meeting_01.txt** – Kickoff: goals, scope, discussion, questions from the team.
- **meeting_02.txt** – First update: progress on previous items, blockers, new tasks.
- **meeting_03.txt** – Later update: continuity, references to “last week”, completion and carryover.

## How to use

1. In the app, create a project (or pick an existing one).
2. Open the project and paste the contents of **meeting_01.txt** into “Upload transcript”. Set meeting title and week, then click **Generate proposal**.
3. Review the AI proposal (current vs proposed actions), then **Approve & save** or **Reject and request changes** with feedback.
4. Repeat with **meeting_02.txt**, **meeting_03.txt**, etc. The AI will update existing action items (completed/carryover) and add new ones based on each meeting.

Transcripts are plain meeting minutes so the AI can infer who said what, what was decided, and what’s left to do.
